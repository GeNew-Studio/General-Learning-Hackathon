# VibeBlog — 一頁 pitch

**看得見思考的製作課。** 先香港小學，再國際。對象 10–14，預設小學密度；中學可選更密的同一條路。

## Hook

孩子現在就能對 AI 說「做一個接水果遊戲」，然後拿到能玩的東西。爸媽看見成品，以為學會了。

## Pain（兒童版，不是大學生版）

大學生至少在學校聽過 structure、algorithm，再用 AI 跳過。  
10–14 **還沒有那層理論**。如果第一個「我會做東西」是 prompt → 完成，心智模型長不出來：不會拆問題、看不見結構、不懂好不好用、不懂安全。

Cursor 把思考藏在後台。誰會主動問「你為什麼這樣做？」字又多，小學生更不會讀。Scratch 教過運算思維，但接不上孩子已經在用的 GenAI。

未來貴的不是打字寫 code，是 method of solving。這個窗口在童年，不是大二 CS。

## Product

Fork VS Code 是長期形態。**VibeBlog** 先把每一次製作寫成看得見的思考日誌。使用方式不像 Cursor：

- AI 不能默默做完
- 思考拆成可見模組；**必須按 Next**
- **動畫承載教學**，小學每卡約 8–15 字
- 可直接問 AI，但預設不靠孩子主動求教
- UX / 安全 / 結構是關卡，不是附註

摩擦就是產品：懂了才准做完。

## Why now / why HK first

香港小學已有運算思維基礎（CoolThink 類），缺的是 GenAI 時代仍強迫看見思考的製作工具。家長焦慮 + 電腦課 40 分鐘 = 可證明「有在學」的場域。同一引擎再賣英語市場（AI literacy）。

## Stakeholders

| 誰 | 在意 | 我們給 |
|---|---|---|
| 孩子 10–14 | 好玩、能給同學看 | 真的在做；流程像關卡 |
| 家長 | 不是濫用 AI | 可回放步驟；孩子能口述為什麼 |
| 小學老師 | 不要再學一個平台 | 一堂課 = 一個小專案 + Next |
| 中學 ICT | 深度、像真開發 | 之後：denser level + IDE 皮 |
| EDB / 政府 | AI 素養，不要只禁 ChatGPT | 正確使用 AI 製作；對齊分解 / 抽象 / 演算法 |
| 大學（5–8 年） | 會想結構的新生 | 上游心智；**現在不當客戶** |
| NGO / STEM | 工作坊 | 90 分鐘同一條流程 |

買單人：家長、小學、課後、教育局相關計劃。大學只當長期 impact。

## Why not

- **Cursor**：優化 done；我們優化懂了才做完
- **ChatGPT**：要主動問、要讀長文
- **Scratch**：有運算思維，沒接上 GenAI 製作

## Ask

證明一件事：非技術家長看孩子按 Next，能看出「在學思考，不是在出片」。先做接水果原型，再嵌進 VS Code workbench。
